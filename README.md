## Course Outcome 3 (CO3)

The following seven assignments focus on advanced Computer Networks concepts, transport-layer protocols, congestion control, web performance, DNS resolution, network traffic management, and protocol selection.

| Task | Assignment Title | Key Topics Covered |
|---|---|---|
| Q1 | Which Socket Gets the Segment? | Socket Demultiplexing, TCP and UDP, Port Numbers, Packet Headers |
| Q2 | Read the Congestion Window | TCP Congestion Control, Congestion Window (cwnd), Slow Start, AIMD, TCP Tahoe and Reno |
| Q3 | Why Does the Home Page Take 8 Seconds? | HTTP Performance, RTT, Persistent Connections, Pipelining, HTTP/2, HTTP/3, Caching |
| Q4 | How Many Queries Reach the University's DNS Server? | DNS Resolution, Recursive and Iterative Queries, DNS Caching, TTL, DNS Records, Anycast |
| Q5 | When Will the Video Call Freeze? | Queueing Theory, M/M/1 Model, Network Delay, Packet Loss, Token Bucket, QoS and DiffServ |
| Q6 | Count the Round Trips Before the First Byte | TCP and TLS Handshakes, TLS 1.2, TLS 1.3, QUIC, 0-RTT and Connection Migration |
| Q7 | Choose the Protocols from First Principles | Protocol Selection, WebRTC, RTP, DTLS-SRTP, HTTP/3, QUIC, WebSocket, DNS and Network Optimization |

### CO3 Learning Outcomes

Through these assignments, I gained practical knowledge of:

- TCP and UDP socket communication and demultiplexing.
- TCP congestion control mechanisms and congestion-window analysis.
- HTTP performance optimization and web-page loading.
- DNS architecture, caching, and query resolution.
- Network queueing, packet delay, packet loss, and Quality of Service (QoS).
- TCP, TLS 1.2, TLS 1.3, and QUIC connection establishment.
- Selecting suitable network protocols for real-world applications.
- Network performance analysis, simulation, and optimization.
